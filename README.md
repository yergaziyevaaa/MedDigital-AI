# MedDigital AI — демонстрационный прототип

Двуязычный (RU/KZ) учебный тренажёр для первого курса «Сестринское дело» ВМК «Эмили».

## Локальный запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload
```

Откройте http://127.0.0.1:8000

## Что уже реализовано

- Вход в систему с двумя ролями и хешированием паролей.
- RU/KZ переключатель.
- Учебный сценарий заполнения карты вымышленного пациента.
- Проверка по фиксированным критериям и сохранение результатов в SQLite.
- Панель преподавателя со сводкой по студентам.

## Что НЕ реализовано

- **Настоящий AI-наставник пока не подключён.** Подсказки формируются по правилам.
- Нет регистрации, сброса пароля, экспорта Excel, административного управления группами.
- Прототип не подготовлен для публичного доступа реальных студентов.

## Перед публикацией в интернете

1. Сменить все демонстрационные пароли и задать сильный `SESSION_SECRET` через переменную окружения.
2. Настроить HTTPS и `HTTPS_ONLY=1`.
3. Перейти с SQLite на управляемую PostgreSQL, настроить резервные копии и миграции.
4. Добавить защиту от CSRF, ограничение попыток входа, управление учётными записями и политику доступа.
5. Провести тестирование безопасности и согласовать обработку персональных данных студентов.
6. Для реального ИИ подключить API на сервере, с ограничением затрат и запретом передачи реальных медицинских данных.

Это учебный прототип, а не медицинская информационная система.
