# MedDigital AI v3

Двуязычный учебный симулятор для первокурсников специальности «Сестринское дело» ВМК «Эмили». **Не является медицинской информационной системой.** Используйте только вымышленные данные пациентов.

## Возможности
- Авторизация студентов и преподавателя, хеширование паролей PBKDF2.
- Электронная карта вымышленного пациента, задания по конфиденциальности и Excel.
- Результаты, панель преподавателя, создание студентов и экспорт CSV.
- AI-наставник через OpenAI API, если задан `OPENAI_API_KEY`. Без ключа — честно обозначенная стандартная подсказка.
- RU/KZ интерфейс, CSRF-токены на формах, базовое ограничение попыток входа.

## Локальный запуск

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`, установите переменные окружения удобным способом (файл `.env` **не загружается автоматически**) или задайте их вручную:

```bash
# Linux/macOS (только для локальной демонстрации)
export SEED_DEMO=1
uvicorn app:app --reload
```

Демо-аккаунты создаются только при `SEED_DEMO=1`, `APP_ENV` не production и пустой базе: `teacher`, `student101`, `student102` / `Demo2026!`. Никогда не используйте их на публичном сайте.

## Публикация

См. `DEPLOYMENT.md`. Перед публичным доступом реальных студентов нужна дополнительная проверка безопасности и политика обработки персональных данных.

## Учебные материалы без ИИ
Добавлены 8 учебных модулей и 32 вопроса с автоматической проверкой, результатами в SQLite и выгрузкой CSV преподавателем. Настоящий ИИ не требуется. Для тестов используется `/courses`. Часть вариантов ответов пока на русском; темы и теория двуязычные.

## Дополнение v4
- 15 учебных модулей, 67 вопросов; 7 новых модулей имеют казахские и русские варианты тестов.
- Существующие 8 модулей содержат русскоязычные вопросы (теория двуязычная); требуется редакторский перевод.
- Результаты тестов сохраняются в `course_results`, экспорт CSV доступен преподавателю.
- Бесплатный Render использует непостоянную SQLite-базу: не используйте для реальных групп без внешней постоянной БД.
- Не используйте настоящие сведения о пациентах.
