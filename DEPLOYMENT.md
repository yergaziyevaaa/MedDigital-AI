# Публикация MedDigital AI v3

**Не запускайте публично с демонстрационными аккаунтами.**

1. Загрузите файлы из этой папки в корень GitHub-репозитория (не загружайте `.env`, `*.db`).
2. Создайте Python Web Service на Render, подключив GitHub.
3. Build command: `pip install -r requirements.txt`.
4. Start command: `uvicorn app:app --host 0.0.0.0 --port $PORT`.
5. Environment variables: `APP_ENV=production`, `HTTPS_ONLY=1`, `SEED_DEMO=0`, `SESSION_SECRET` (случайные 48+ символов), `TEACHER_USERNAME` и `TEACHER_PASSWORD` (уникальный пароль 12+ символов).
6. При первом запуске создаётся преподаватель из переменных окружения. Удалите `TEACHER_PASSWORD` из настроек после успешной инициализации, если это возможно без потери доступа. Не меняйте `SESSION_SECRET` без необходимости — это завершит сессии.
7. Для настоящего ИИ добавьте `OPENAI_API_KEY` и при необходимости `OPENAI_MODEL`; ключ храните только в переменных окружения хостинга. Использование API может быть платным.
8. `DATABASE_PATH` должен указывать на **постоянный диск**. Бесплатный эфемерный диск не сохраняет данные между перезапусками. SQLite годится только для небольшой демонстрации; для реальных групп необходима миграция на PostgreSQL.
9. Проверьте `https://ваш-сайт/health`, вход преподавателя, создание студента и учебные задания.

## Ограничения и безопасность

- Ограничение входа хранится в памяти процесса и сбрасывается при перезапуске; для публичного проекта нужен внешний rate limiter.
- Нет сброса пароля, полноценного аудита, согласий на обработку данных, резервного копирования, PostgreSQL, изоляции по преподавателям.
- Перед использованием реальными студентами требуется независимое тестирование безопасности и согласование правил обработки персональных данных.
- Все сценарии демонстрационные, не используйте реальные сведения о пациентах.
